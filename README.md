# WebStudio

![Скріншот сайту WebStudio](./images/webstudio-preview.png)

WebStudio — адаптивний односторінковий сайт вебстудії, що презентує послуги компанії, команду та приклади виконаних проєктів. Сайт містить мобільну навігацію, інтерактивні картки портфоліо, модальне вікно для замовлення послуги та форму підписки.

[Переглянути сайт](https://anastasiia-kosh.github.io/goit-markup-hw-06/) · [Репозиторій](https://github.com/Anastasiia-Kosh/goit-markup-hw-06)

## Основні можливості

- Адаптивна верстка для мобільних пристроїв, планшетів і комп’ютерів
- Мобільне навігаційне меню з анімованим відкриттям і закриттям
- Модальне вікно з контактною формою, що відкривається кнопкою **Order Service**
- Адаптивні зображення для різних розмірів екрана та щільності пікселів
- Інтерактивні картки портфоліо з текстовим оверлеєм
- Секція команди з іконками соціальних мереж
- Форма підписки у футері
- Стилі для станів наведення та фокуса інтерактивних елементів
- SVG-спрайт для іконок

> Контактна форма та форма підписки є демонстраційними й не надсилають дані на сервер.

## Як запустити проєкт

Проєкт не потребує встановлення додаткових залежностей або збірки.

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Anastasiia-Kosh/goit-markup-hw-06.git
   ```

2. Перейдіть до папки проєкту:

   ```bash
   cd goit-markup-hw-06
   ```

3. Відкрийте файл `index.html` у браузері або запустіть проєкт за допомогою локального сервера, наприклад Live Server.
